Phase 9 — Training Dynamics

This page tracks how the model's representations develop over the course of training — looking for phase transitions where individual distance classes suddenly become solvable, and measuring when each layer starts linearly encoding distance.

Results are generated by re-running training with per-epoch checkpoints, then running the analysis script:

uv run cube-train --save-every 1 uv run python -m interp.grokking

Once generated, docs/grokking_results.html is replaced in-place with the interactive Plotly charts.

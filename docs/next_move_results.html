Phase 10 — Next-Move Prediction Variant

Question: Does an implicit distance representation emerge when the model is trained on next-move prediction rather than distance classification?

Method: Train an identical architecture on next-move prediction (18 classes), then compare per-layer optimal-distance probe MAE against the distance-supervised baseline.

Finding: The next-move task is near-impossible (6.3% vs 5.6% random baseline) — scramble moves are unpredictable from cube state alone. Both models start with the same embedding-layer distance MAE (0.98), but only the distance-supervised model improves it in transformer blocks (0.40 vs 0.82 at L3). Distance representation requires direct supervision.
